Privacidade

← Voltar

Este site de monitoramento de status utiliza a estrutura do Upptime e não coleta, rastreia nem armazena quaisquer dados pessoais, cookies de navegação ou informações de telemetria de usuários.

As checagens de disponibilidade são executadas de forma automatizada pelo GitHub Actions e a página estática é hospedada pelo GitHub Pages.

A proteção de rota e o tráfego dos serviços são intermediados pela Cloudflare para mitigação de ataques.
