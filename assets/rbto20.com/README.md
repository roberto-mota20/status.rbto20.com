# rbto20.com

Página pessoal, links e publicações ([rbto20.com](https://rbto20.com)), construída com HTML, CSS e JavaScript puros e hospedada no Cloudflare Workers.

## Publicações (/publ)

Para adicionar novas publicações em Markdown (`.md`) ou MDX (`.mdx`):
1. Basta adicionar o arquivo diretamente na pasta `publicacoes/` (ex: `publicacoes/meu-artigo.md`).
2. O sistema indexa e extrai o título e resumo automaticamente a partir das primeiras linhas de texto.
3. Acesse em `/publ` ou diretamente via `/publ?post=meu-artigo`.
